Word Clock Firmware Installer

One-time setup to give your clock automatic updates. After this, it updates itself over WiFi — you never need this page again.

  1. Use a desktop Chrome or Edge browser (not a phone, not Safari).
  2. Plug the clock into this computer with a USB data cable (a charge-only cable will not work).
  3. Click Install below and pick the clock's serial port when prompted.
  4. Wait for it to finish, then unplug. The clock keeps its WiFi and settings.

If asked, do not choose “Erase device” — a normal install preserves your WiFi network, timezone, and layout. Only erase if you want to start completely fresh.
